# Monsta Choppa PC

Monsta Choppa PC is a top-down dungeon crawler branch that keeps shared ScriptableObject databases, event channels, pooling, saves, and UI architecture from the VR project while replacing VR-first interaction, camera, and combat control paths with desktop equivalents.

## Current Sprint

- **Week 1 Goal:** Ship playable room-to-room flow with lock/clear progression.
